# Gate 15A 结果总账（冻结）：Target-Normal Local Covariance Mixture

> 冻结于 tag `gate15a_closed`。
> **判决：FAIL。局部多模态协方差没有超过全局协方差，且「簇↔协方差」的配对不起作用。**
> 按预注册分支 → **转向 multi-layer DINO statistics**。

---

## 最终结论（严谨表述）

> **把 target normal 从「一个全局协方差」升级为「K 个局部协方差的混合」
> （K=2/4/8，hard/soft assignment，向全局协方差 shrink），
> 在 K=2/4/8 与 ρ=0.25/0.5/0.75 的全部 12 个配置中**没有一个超过全局协方差**
> （−0.31 ~ +0.09）。**
> **且反事实显示：保留每个 patch 的簇归属、只把局部协方差随机重排，
> 结果几乎不变（K=2/4 完全为 0，K=8 为 +0.27）。**
> **即：normal 的局部 mode 划分与它的协方差之间不存在有作用的对应关系。**

## 2. 反事实：配对没有作用

保留每个 patch 的**簇归属**，只把局部协方差在簇之间随机重排：

| K | correct − shuffled | better |
|---|---|---|
| 2 | **+0.00** | 0/15 |
| 4 | **+0.00** | 0/15 |
| 8 | +0.27 | 7/15 |

**K=2/4 完全为 0。** 所以「这个正常 mode 应该配这个协方差」这件事
在数据里不存在——重排后结果一模一样。

对照 Gate 12 的全局版本：own − shuffled = **+2.6（12/15）**。
**全局协方差的配对是真实起作用的；局部协方差的配对不是。**

## 3. 判决与下一支

预注册分支：

| 分支 | 判定 |
|---|---|
| local > 86.7，≥10/15，且 shuffled 明显更低 | ❌ FAIL |
| **local ≤ 86.7 → 停止在 final-layer normal 分布上做更复杂统计** | ✅ 命中 |

至此在 final-layer DINO 的 target normal 分布上已经逐级试过：

| 统计量 | 结果 |
|---|---|
| 一阶 μ（centering） | −0.58 ❌ |
| 对角二阶 σ（z-score） | −0.22 ❌ |
| **完整二阶 Σ（全局协方差）** | **+1.8 ✅ 唯一的正结果** |
| 局部多模态 Σ（本 gate） | ~0 ❌ |
| source defect 学到的 residual（13B/14B） | 负 ❌ |

**只有全局二阶结构有效，更复杂或更细粒度的统计都没有增益。**

因此进入预注册的下一支：

> **Multi-layer DINO statistics** —— final layer 可能只提供 object semantics，
> 而 defect morphology 需要中层纹理 / 边缘 / 局部形状。

具体做法：取
$$z^{mid},\ z^{late},\ [z^{mid},\ z^{late}]$$
每一层分别做已验证过的 $\Sigma^{-0.5}$（**不重新开始训练网络**）。

## 4. 一个贯穿全局的模式（现在可以正式写下）

| 信息源 | 效果 |
|---|---|
| **target normal 的全局协方差** | **+1.8 ~ +2.4 ✅** |
| target normal 的一阶/对角二阶/局部多模态 | ≈0 ❌ |
| 任何 source defect 监督（retrieval / generator / selector / residual） | 负 ❌ |

> **十三轮 gate 下来，唯一稳定提供正收益的信息是
> 「target normal 的全局二阶结构」，而且它不需要任何训练。**

这个结论与最初的立项假设（迁移 source defect knowledge）是**不同**的，
但它是数据支持的那一个。

## 继承到下一阶段的强制方法纪律

1. **反事实必须与主配置同源同脚本。** 本次 L1 在脚本内重算（86.5 vs 13A 的 86.7），
   比较才成立。
2. **「更复杂的统计量」必须逐级验证，不能假定有效。**
   本次从 μ → σ → Σ → local Σ 逐级测，只有 Σ 有效。
3. **配对类结构的检验必须做置换反事实**（本次 K=2/4 直接归零）。
4. **一个 Gate 之前先做 1-object sanity test**（loss finite / embedding finite /
   grad norm > 0 / update norm > 0 / 20–50 步后 loss 有变化）——
   本 gate 无训练，但该纪律对后续 learned gate 继续强制。
