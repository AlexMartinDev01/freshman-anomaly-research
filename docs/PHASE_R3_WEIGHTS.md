# Phase R 步骤 3（稳健性）：聚合增益是不是"权重假象"？

> 冻结于 tag `phase_r3_weights`。
> **判决：不是。定位增益在完全不用权重时依然成立（AUPRO +3.05）。**
> **图像级的退化同样不是权重假象——三种方案下都在。**

---

## 1. 为什么必须查这个

`agg_all3` 的做法是：先按 object 的**测试集**统计量对每层距离图做 z-score，
再等权平均。于是有一个正当的质疑：

> 增益是不是来自"用测试集统计量挑出来的层权重"？

先把能说的说死：**该 z-score 是全局仿射变换，对同一层的所有 map 完全相同，
因此不可能改变任何排秩指标**——image AUROC、pixel AUROC、AUPRO 全部对它有不变性。
它唯一的作用是决定层间权重：

    agg = mean_l (m_l - μ_l)/σ_l = mean_l m_l/σ_l  (相差一个常数)

所以"指标被抬高"不成立；"权重是 transductive 的"成立。
本节把这个 transductive 成分**彻底移除**再测一次。

## 2. 三种权重方案

| config | 权重来源 |
|---|---|
| `agg_all3_testz` | 测试集统计量（= 原 `agg_all3`） |
| `agg_all3_trainz` | **只用训练集**：固定抽 1024 个训练 patch 当 query，对同 object 训练池的固定 20000 个 patch 求 1-NN 距离，用其 (μ, σ)。**全程不碰任何测试图** |
| `raw_mean` | **完全不加权**：三张原始距离图直接取平均 |

15 objects × shots {1,4,8} × 3 splits = 135 格 × 4 config = 540 行。

## 3. 结果

| metric | final_raw | testz | trainz | raw_mean |
|---|---|---|---|---|
| img_AUROC | 96.13 | 95.77 (**−0.36**) | 95.72 (**−0.41**) | 95.58 (**−0.55**) |
| px_AUROC | 96.55 | 97.27 (**+0.72**) | 97.27 (**+0.72**) | 97.22 (**+0.67**) |
| AUPRO | 74.17 | 77.72 (**+3.55**) | 77.35 (**+3.18**) | 77.22 (**+3.05**) |

更好格子数（AUPRO）：testz 100/135、trainz 105/135、raw_mean 101/135。

## 4. 结论

**两条都稳：**

1. **定位增益不是权重假象。**
   即使把层权重完全去掉（`raw_mean`），AUPRO 仍有 **+3.05**、px_AUROC **+0.67**。
   换成完全归纳（训练集）的权重，AUPRO **+3.18**。
   三种方案彼此差距很小（+3.05 ~ +3.55），**说明增益来自"多用两层特征"本身，
   而不是来自任何权重选择**。transductive 质疑就此关闭。

2. **图像级退化同样不是权重假象。**
   三种方案全部为负（−0.36 / −0.41 / −0.55），且不加权时更差。
   也就是说，**把中层平均进来这件事本身**在图像级是有代价的，
   不是"权重没调好"。这与 `PHASE_R3_LAYER_CONFIRM.md` 的 screw 机制一致。

## 5. 对 `agg_all3` 的最终表述

> **多层平均（mid + midlate + final）在定位上带来稳健的正收益
> （AUPRO +3.05 ~ +3.55，不依赖任何权重方案），
> 同时在图像级带来稳健的小幅负收益（−0.36 ~ −0.55），
> 且该负收益高度集中于单一 object（screw，−10.73）。**

**因此 `agg_all3` 不是一个可以无条件替换 final-only 的 baseline。**
它是一组"定位换检测"的交换。是否采用，取决于下游更看重哪个指标——
这个决定必须在**下一个预注册判据**里明确，不能靠事后挑权重。

## 6. 限制

- shots 为 {1,4,8}（主确认运行是 {1,2,4,8}），因此数值与
  `PHASE_R3_LAYER_CONFIRM.md` 的均值不完全可比；本节结论是
  **同一次运行内三种权重方案的对比**，这个对比与 shot 集合无关。
- `trainz` 的 (μ, σ) 每个 object 只估一次（固定采样、固定种子），
  未随 shot 变化。这是刻意的：目的是给一个**与 bank 无关的归纳尺度**，
  而不是再引入一个可调量。
